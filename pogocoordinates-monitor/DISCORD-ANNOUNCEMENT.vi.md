**PoGo Radar v0.3.7 — extension mới cho Edge / Chrome**

Tên mới và icon radar mới. Giữ máy thức khi chạy (màn hình vẫn có thể tắt), bảo vệ tab Search và tự thử lại khi Search bận/quá giờ. Chọn 0 phút để chạy đến khi dừng. Giữ trình duyệt mở; hết phiên web cần đăng nhập lại.

Tự Search PoGo Coordinates, lọc Top IV + PvPoke. Đóng popup vẫn thấy bảng trạng thái trên trang. Mỗi kết quả gửi hai tin Discord riêng: thẻ thông tin Pokémon, rồi tin văn bản chỉ có tọa độ. Trên điện thoại, nhấn giữ tin → Sao chép văn bản để lấy đúng tọa độ.

**Cài:** tải ZIP → giải nén → edge://extensions → Developer mode → Load unpacked → chọn thư mục có manifest.json.
**Dùng:** đăng nhập PoGo Coordinates, chọn Stats/PvP và bộ lọc trên web → popup Cài đặt → mã bạn bè, chu kỳ, ngưỡng PvP và webhook của bạn → Lưu → Chạy tự động.
Giữ Edge và tab PoGo mở, có thể chạy nền. Cập nhật bản cũ: chép đè → Tải lại extension → F5 trang PoGo. Không gỡ extension để giữ cài đặt.

Đính kèm file pogocoordinates-monitor-v0.3.7.zip khi đăng tin này.

Cột PvPoke nằm cạnh CP / LVL / IV trên kết quả Search ở chế độ PvP. Hạng theo Great 1500 / Ultra 2500; khi xét tiến hóa, hiện loài có hạng tốt nhất. Dấu — là chưa có hạng. Đây là hạng loài, không phải hạng IV.
