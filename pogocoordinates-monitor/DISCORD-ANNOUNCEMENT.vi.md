**PoGo Monitor v0.3.0 — extension mới cho Edge / Chrome**

Tự Search PoGo Coordinates, lọc Top IV + PvPoke. Discord có ảnh Pokémon, dòng hạng in đậm và tọa độ riêng để sao chép.

**Cài:** tải ZIP → giải nén → edge://extensions → Developer mode → Load unpacked → chọn thư mục có manifest.json.
**Dùng:** đăng nhập PoGo Coordinates, chọn Stats/PvP và bộ lọc trên web → popup Cài đặt → mã bạn bè, chu kỳ, ngưỡng PvP và webhook của bạn → Lưu → Chạy tự động.
Giữ Edge và tab PoGo mở, có thể chạy nền. Cập nhật bản cũ: chép đè rồi Tải lại, không gỡ extension.

Đính kèm file pogocoordinates-monitor-v0.3.0.zip khi đăng tin này.
